# Word Partners

Learn English collocations on iPhone: flashcards with spaced repetition, a two-step quiz (choose, then write), real-life examples and Russian translations.

Open https://altmanhellen.github.io/word-partners/ in Safari, then Share → Add to Home Screen.

- `app.html` is the app itself. Edit it, then run `sh build.sh` to rebuild `index.html`.
- `sw.js` keeps a copy for offline use. Change `CACHE` in it when you publish an update.
